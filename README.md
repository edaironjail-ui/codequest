# CodeQuest

CodeQuest est un prototype de site web d'apprentissage gamifié pour apprendre :
- HTML
- terminal Linux Mint
- terminal Windows
- progression et badges
- tableau de bord de statistiques
- synchronisation temps réel (architecture Firebase prête)

## Stack
- React + Vite
- Firebase (authentification / Firestore / config prête)
- CSS personnalisé pour un design immersive et responsive

## Installation
```bash
npm install
npm run dev
```

## Variables d'environnement
Copiez `.env.example` vers `.env` et ajoutez vos identifiants Firebase.
